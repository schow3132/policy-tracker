# 2026 Policy Tracker

A static website that shows the Government & Congress Policy Tracker spreadsheet: the stated policy positions of 2026 Senate and Governor nominees in Michigan, Texas, Ohio, Wisconsin and Kansas. Every claim links to its source.

## What's in the site

| Tab | What it shows | Spreadsheet sheet |
|---|---|---|
| Overview | Headline numbers, statewide race results, how the policies split, House seats by state | Dashboard, Statewide Races, Policy Index |
| Policies | Each indexed policy with one dot per nominee; open a policy to read every claim | Policy Index + Claims Log |
| Stance grid | Every candidate × every policy; each cell links to its source | Claims Log |
| Claims | Searchable, filterable log of every claim with source links | Claims Log |
| Candidates | How fleshed out each platform is, plus positions by issue | Candidate Scorecard, Policy Detail |
| Money | Senate fundraising and donor size mix | Statewide Races, Donor Profile |
| House | All House nominees with FEC totals | House Races |
| Method | Sources, method, gaps and definitions | Sources & Method |

## Files

- `index.html`, `styles.css`, `app.js`: the website (no build step, no frameworks).
- `data/tracker.json`: the spreadsheet's contents, generated by `update-data.ps1`.
- `update-data.ps1`: rebuilds `data/tracker.json` from the .xlsx.

## Updating the data after you edit the spreadsheet

1. Save the workbook (keep the sheet names and column header labels the same; adding rows is fine).
2. In this folder, run:

   ```
   powershell -ExecutionPolicy Bypass -File update-data.ps1
   ```

   By default it reads `Downloads\Government  Congress Policy Tracker.xlsx`. For a different file, add `-Xlsx "C:\path\to\file.xlsx"`.
3. Commit and push `data/tracker.json`. The site picks up the new data on the next load.

## Publishing with GitHub Pages (GitHub Desktop)

1. In GitHub Desktop: **File > Add local repository**, choose this `policy-tracker` folder, and click **create a repository** when it offers.
2. Click **Publish repository**. Untick "Keep this code private" (free GitHub Pages needs a public repo).
3. On github.com, open the repo: **Settings > Pages > Build and deployment**, Source **Deploy from a branch**, Branch **main**, folder **/ (root)**, then **Save**.
4. After about a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Previewing locally

Opening `index.html` straight from disk won't load the data (browsers block that). Use a local server, or just check the published site.
